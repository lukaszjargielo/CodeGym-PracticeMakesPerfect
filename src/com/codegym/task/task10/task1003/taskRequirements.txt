
Add one type conversion to get the following answer: b = 0

Requirements:
•	The program should display text on the screen.
•	Don't change the screen output command.
•	The main() method must contain a float variable f.
•	The main() method must contain an int variable i.
•	The main() method must contain an int variable b.
•	Don't change the initial value of the variables during initialization. You can only add cast operators.
•	The program should display the number 0.

package com.codegym.task.task10.task1003;

/* 
Task No. 3 about integer type conversions

*/

public class Solution {
    public static void main(String[] args) {
        float f = (float) 128.50;
        int i = (int) f;
        int b = (int) (i + f);
        System.out.println(b);
    }
}
