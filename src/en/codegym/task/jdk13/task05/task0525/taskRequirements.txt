
Using the Duck class as a pattern, create Cat and Dog classes.
What do you think the toString method in the Cat and Dog classes should return?

In the main method, create two objects of each class and display them on the screen.
Duck objects have already been created and are displayed on the screen.

Requirements:
•	Create a Cat class.
•	Create a Dog class.
•	The Cat class must correctly implement the toString method.
•	The Dog class must correctly implement the toString method.
•	In the main method, create two Cat objects.
•	In the main method, create two Dog objects.
•	Display all the created objects on the screen.
