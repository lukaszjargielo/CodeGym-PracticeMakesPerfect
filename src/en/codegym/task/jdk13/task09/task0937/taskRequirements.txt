The String variable must be initialized with a string literal.

Requirements:
•	Variables of all primitive types must be created in the Solution class.
•	A String variable must be created in the Solution class.
•	The variables of primitive types must be initialized with the appropriate literals when they are declared.
•	The String variable must be initialized with a string literal when it is declared.
•	No methods should be created in the Solution class.
